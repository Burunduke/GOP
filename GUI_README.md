# GUI для GOP - Гиперспектральная обработка и анализ растений

Веб-интерфейс для системы GOP, обеспечивающий удобную работу с гиперспектральными данными и анализ растительности.

## Особенности

- **Современный веб-интерфейс** на основе Dash и Bootstrap
- **Интуитивная навигация** для работы с проектами
- **Визуализация данных** в реальном времени
- **Асинхронная обработка** больших объемов данных
- **Интеграция с GOP** через адаптеры
- **Адаптивный дизайн** для различных устройств

## Установка

### 1. Установка зависимостей

```bash
# Установка GUI зависимостей
pip install -r requirements-gui.txt

# Или установка через pyproject.toml
pip install -e .[gui]
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```bash
# Настройки GUI
DEBUG=True
HOST=0.0.0.0
PORT=8050
SECRET_KEY=your-secret-key-here

# Настройки базы данных
DATABASE_URL=sqlite:///gop_gui.db

# Настройки Redis (опционально)
REDIS_URL=redis://localhost:6379/0

# Настройки файловой системы
UPLOAD_FOLDER=data/uploads
PROJECTS_FOLDER=data/projects
CACHE_FOLDER=data/cache

# Настройки GOP
GOP_CONFIG_PATH=config/config.yaml
```

### 3. Создание необходимых директорий

```bash
mkdir -p data/uploads data/projects data/cache data/sessions logs
```

## Использование

### 1. Доступ к интерфейсу

После запуска откройте в браузере:
- **Разработка**: http://localhost:8050
- **Продакшен**: http://your-server:8050

### 2. Основные функции

#### Создание проекта
1. Нажмите "Новый проект" в боковой панели
2. Введите название и описание проекта
3. Нажмите "Создать"

#### Загрузка данных
1. Выерите проект или создайте новый
2. Нажмите "Загрузить файлы"
3. Перетащите файлы в область загрузки или выберите их
4. Поддерживаемые форматы: BIL/HDR, TIFF, DAT

#### Обработка данных
1. После загрузки файлов нажмите "Настройки обработки"
2. Выберите тип сенсора и вегетационные индексы
3. Настройте опции обработки
4. Нажмите "Начать обработку"

#### Визуализация результатов
1. Перейдите в раздел "Анализ"
2. Выберите тип визуализации
3. Настройте параметры отображения
4. Исследуйте результаты интерактивно

## API

GUI предоставляет REST API для интеграции с другими системами:

### Основные эндпоинты

- `GET /api/health` - Проверка состояния системы
- `GET /api/config` - Получение конфигурации
- `GET /api/projects` - Список проектов
- `POST /api/projects` - Создание проекта
- `POST /api/projects/{id}/files` - Загрузка файлов
- `POST /api/process` - Запуск обработки
- `GET /api/process/{task_id}` - Статус обработки
- `GET /api/indices` - Список индексов

### Пример использования

```python
import requests

# Создание проекта
response = requests.post('http://localhost:8050/api/projects', json={
    'name': 'Тестовый проект',
    'description': 'Описание проекта'
})
project = response.json()

# Загрузка файла
with open('data.bil', 'rb') as f:
    files = {'files': f}
    response = requests.post(
        f'http://localhost:8050/api/projects/{project["id"]}/files',
        files=files
    )

# Запуск обработки
response = requests.post('http://localhost:8050/api/process', json={
    'project_id': project['id'],
    'config': {
        'sensor_type': 'hyperspectral',
        'selected_indices': ['NDVI', 'EVI']
    }
})
task = response.json()
```

## Конфигурация

### Основные параметры

- `DEBUG`: Режим отладки (True/False)
- `HOST`: Хост для запуска сервера
- `PORT`: Порт для запуска сервера
- `SECRET_KEY`: Секретный ключ для сессий
- `MAX_FILE_SIZE`: Максимальный размер файла (байты)

### Настройки GOP

- `GOP_CONFIG_PATH`: Путь к конфигурации GOP
- Интеграция с модулями обработки данных
- Настройка вегетационных индексов

## Устранение неполадок

### Частые проблемы

1. **Ошибка импорта GOP модулей**
   - Убедитесь что GOP установлен в режиме разработки
   - Проверьте PYTHONPATH

2. **Проблемы с Redis**
   - Проверьте что Redis сервер запущен
   - Убедитесь в правильности URL подключения

3. **Ошибки загрузки файлов**
   - Проверьте права доступа к директориям
   - Убедитесь в достаточном месте на диске

### Логирование

Логи сохраняются в `logs/gui.log`:
```bash
# Просмотр логов
tail -f logs/gui.log

# Поиск ошибок
grep ERROR logs/gui.log
```
