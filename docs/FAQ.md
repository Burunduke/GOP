# Часто задаваемые вопросы (FAQ)

## Общие вопросы

### Что такое GOP?
GOP (Геопространственная обработка ортофотопланов) - это научная библиотека для обработки гиперспектральных данных и анализа состояния растений с использованием вегетационных индексов.

### Какие форматы файлов поддерживаются?
- BIL/HDR (ENVI)
- TIFF/GeoTIFF
- DAT файлы с метаданными

### Какие вегетационные индексы доступны?
- NDVI (Normalized Difference Vegetation Index)
- EVI (Enhanced Vegetation Index)
- SAVI (Soil Adjusted Vegetation Index)

## Использование

### Как создать новый проект?
1. Нажмите кнопку "Новый проект" в боковой панели
2. Введите название проекта
3. Нажмите "Создать"

### Как загрузить данные?
1. Нажмите кнопку "Загрузить файлы"
2. Выберите файлы или перетащите их в область загрузки
3. Нажмите "Загрузить"

### Как начать обработку?
1. Загрузите данные
2. Нажмите "Настройки обработки"
3. Выберите параметры обработки
4. Нажмите "Начать обработку"

## Проблемы и решения

### Ошибка при загрузке файлов
- Проверьте формат файла
- Убедитесь, что файл не поврежден
- Проверьте размер файла (макс. 10GB)

### Обработка занимает слишком много времени
- Убедитесь, что выбраны только необходимые индексы
- Закройте другие ресурсоемкие приложения
- Рассмотрите использование более мощного оборудования

### Не отображаются результаты
- Проверьте, что обработка завершена
- Убедитесь, что выбран правильный индекс для визуализации
- Проверьте настройки цветовой карты
