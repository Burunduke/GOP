# Архитектура проекта GOP

Этот документ описывает архитектуру проекта GOP (Геопространственная обработка ортофотопланов).

## 🏗️ Обзор архитектуры

Проект GOP построен с использованием модульной архитектуры с четким разделением ответственности между компонентами. Архитектура разработана для обеспечения масштабируемости, поддерживаемости и тестируемости.

## 📁 Структура проекта

```
src/
├── core/                    # Основные классы и конвейеры
│   ├── config.py           # Конфигурация системы
│   └── pipeline.py         # Основной конвейер обработки
├── processing/             # Обработка данных
│   ├── hyperspectral/      # Обработка гиперспектральных данных
│   │   ├── cache.py        # Утилиты кэширования
│   │   ├── corrections.py  # Коррекция данных
│   │   ├── denoising.py    # Снижение шума
│   │   ├── processor.py    # Основной процессор
│   │   └── validators.py   # Валидация данных
│   └── orthophoto.py       # Создание ортофотопланов
├── indices/                # Вегетационные индексы
│   ├── calculator.py       # Калькулятор индексов
│   └── definitions.py      # Определения индексов
├── segmentation/           # Сегментация изображений
│   └── segmenter.py        # Сегментатор изображений
└── utils/                  # Вспомогательные функции
    ├── exceptions.py       # Иерархическая система исключений
    ├── file_utils.py       # Файловые операции
    ├── gdal_utils.py       # Утилиты интеграции GDAL
    ├── image_utils.py      # Утилиты обработки изображений
    ├── logger.py           # Логирование
    ├── math_utils.py       # Безопасные математические операции
    ├── validators.py       # Фреймворк валидации данных
    └── visualization.py    # Визуализация
```
